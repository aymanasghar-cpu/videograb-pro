📖 How to export cookies (Netscape format)

  1. Install the cookies.txt browser extension (Chrome/Firefox).
  2. Log into YouTube / the site you want to download from.
  3. Click the extension icon → Export → copy the text.
  4. Paste it in the box below and click Save Cookies.
  5. Check "Use saved cookies" in the download tabs.
